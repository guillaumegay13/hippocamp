# Current state

Relay verifies HMAC-SHA256 webhooks and queues production deliveries in Postgres (DATABASE_URL or PG*). Redis removed. Acceptance is 202 after persistence. QueueStore abstracts storage; MemoryStore and inline delivery remain. src/app.ts exports createApp; src/server.ts owns Pool and worker lifecycle.

Atomic SKIP LOCKED claims use 60-second recovery leases and 30-second outbound timeouts. Five attempts total; retry only 5xx. SOURCES[source].retryDelaysMs optionally supplies four integer delays 0–2147483647, defaults 100/200/400/800. Invalid config fails startup. Worker uses availability times and current config for next retry, including old deliveries; existing scheduled times remain. Attempts recorded before sending; interruption can duplicate or consume an attempt. Recipients deduplicate stable delivery IDs.

GET /admin/deliveries returns {deliveries,nextCursor}; limit default 100/max 1000, malformed pagination 400. Ascending receipt timestamp plus bytewise ID keyset order. Cursor preserves Postgres microseconds for backfills. No snapshot: inserts before cursor require a new traversal. Apply 004_admin_pagination.sql for index. Detail and list allowlist id/source/target/receivedAt (Unix ms)/status/attempts. Attempt endpoint returns safe timing/status/outcomes; absent legacy history yields []. Never expose payloads/raw errors. Unknown IDs 404, storage failures generic 503. Deployment provides admin access controls.
