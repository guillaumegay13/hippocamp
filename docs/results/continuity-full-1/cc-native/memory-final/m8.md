- The client host runs Node 20, so don't use any API newer than Node 20 (even though local node / @types/node are 22).
- Ask the user before adding any new dependency.
- Tests stay on built-in `node:test` (no jest/vitest/mocha).
- Any timestamp in an API response must be epoch milliseconds (number); the client SDK expects that.
- Keep diffs to what the task needs; don't touch unrelated files.
- Ops won't run Redis. Postgres (`pg`) is approved infra/dep; persistent state goes there. Tests use fakes, never a live DB.

**Why:** the user stated these as standing constraints for relay (2026-11-04).
**How to apply:** check API availability against Node 20 docs; propose a dep and wait for an OK instead of installing it; write tests with node:test + node:assert.
