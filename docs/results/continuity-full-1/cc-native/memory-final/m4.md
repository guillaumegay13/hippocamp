As of 2026-11-04, vendor_c is coming soon, but its rows must NOT be posted to the warehouse. Finance hasn't confirmed whether vendor_c's `totalPrice` includes VAT.

**Why:** if totalPrice is VAT-inclusive and gets loaded as `amount` next to the other vendors' figures, the warehouse ends up with mixed-basis amounts that are hard to clean up later.

**How to apply:** it's fine to build vendor_c reading/mapping, but block or skip posting for vendor_c (and don't run a load or a smoke that would send its rows to prod) until the user says finance has confirmed. Ask before lifting the block. See also [[vendor-a-history-load]].
