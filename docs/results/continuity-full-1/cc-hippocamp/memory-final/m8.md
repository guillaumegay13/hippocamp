No attempt history existed before (Delivery only had an `attempts` counter). Added Store.recordAttempt/attempts (MemoryStore keeps a per-delivery log, separate from Delivery so the queue row JSON doesn't grow). deliver() records each try before store.save: {attempt, startedAt, durationMs, statusCode (null on network error), outcome delivered|retrying|failed, nextAttemptAt?, error?}; timestamps epoch ms from the injectable now(). Admin route returns {id, attempts} via allowlist toAttemptSummary; 404 for unknown delivery; no request/response bodies stored. Choices made by me, unconfirmed: field names, storing fetch error.message, empty list for deliveries with no attempts. Open: history is in-memory only (lost on restart) like MemoryStore; a PostgresStore would need a delivery_attempts table. Uncommitted at end of session.
