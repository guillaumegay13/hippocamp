# Preferences

## Changelog (all repos, set 2026-11-04)
- Every user-facing change gets a line in `CHANGELOG.md` under an `## Unreleased` heading.
- If the repo has no `CHANGELOG.md`, create it (`# Changelog` + `## Unreleased`) when making the first user-facing change.
- Internal-only changes (tooling, tsconfig, refactors with no behavior change, tests) don't need an entry.
